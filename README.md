# Dialect for Mac

[Download the latest release](https://github.com/natedog23z/dialect-world-releases/releases/latest).

Choose the installer for your Mac:

- **Apple Silicon** (M1 or newer): the file ending in `arm64.dmg`.
- **Intel**: the file ending in `x64.dmg`.

Open the DMG, drag Dialect into Applications, then open Dialect from Applications.
Enter your email and the code emailed to you. Create a dialect or accept an invite,
then connect Claude when prompted.

“Say it” turns your voice into editable text on macOS 26 or later. Allow microphone
access when asked. Apple's speech model may need to download the first time.

The ZIPs, blockmaps and `latest-mac.yml` support automatic updates. Use the DMG for
your first installation. The `release-config` entry holds update safety settings;
it is not an app download.
